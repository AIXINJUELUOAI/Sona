# Sona

一款面向 Android 的本地与网易云音乐播放器。

Sona 采用 Material 3 Expressive 设计，将本地音乐、在线音乐和歌词体验融入统一界面。支持动态配色、两种播放器样式，以及固定和弹幕两种悬浮歌词。

**1.0 Beta · Android 10 及以上**

[下载与版本说明](https://github.com/AIXINJUELUOAI/Sona/releases) · [问题反馈](https://github.com/AIXINJUELUOAI/Sona/issues)

## 功能亮点

### 本地与在线音乐

- 扫描设备音乐库，离线播放本地歌曲，管理本地收藏。
- 网易云音乐搜索、歌单浏览、每日推荐与私人 FM，支持二维码和网页登录。
- 在同一搜索页查找本地与网易云歌曲。
- 查看最近播放、收藏歌曲与个性化混合推荐。

### 播放体验

- 默认与大胆两种播放器样式，支持横屏播放布局。
- 根据专辑封面生成播放器配色，提供系统、浅色和深色主题。
- 后台播放、播放队列、顺序播放、列表循环、单曲循环与随机播放。
- 记忆播放队列和进度，支持媒体输出切换。
- 系统媒体卡片支持播放控制、爱心收藏和“词”悬浮歌词开关。

### 歌词体验

- 同步歌词与译文，当前演唱行自动居中，支持点击歌词跳转。
- 读取本地音频的内嵌歌词，以及已授权音乐文件夹中的同名 LRC 文件。
- 固定悬浮歌词支持一条或两条显示，可直接在悬浮窗中调整位置与大小。
- 弹幕悬浮歌词在屏幕上半区滚动，支持原文与译文一起显示。
- 调整歌词字号、不透明度与弹幕速率，从 8 种预设颜色中选择，并为不同应用设置专属配色。

### 收听统计

- 查看收听记录、有效收听次数与播放偏好。
- 结合收藏和收听记录生成混合推荐，相关统计保存在设备上。

## 下载与安装

前往 [Releases](https://github.com/AIXINJUELUOAI/Sona/releases) 查看版本说明并下载 APK。安装时，如系统提示，请为下载 APK 所用的浏览器或文件管理器允许安装应用。

- **系统要求：** Android 10（API 29）或更高版本。
- **本地音乐：** 授予音乐与音频访问权限后，即可扫描和播放设备中的歌曲。
- **在线音乐：** 需要网络连接；每日推荐、私人 FM 和云端收藏等功能需要登录网易云账号。歌曲可播放范围与音质取决于账号权益及服务端返回结果。

## 悬浮歌词与权限

在设置中开启“悬浮歌词”，选择默认或弹幕样式。也可以通过系统媒体卡片中的“词”按钮快速开关。

| 权限 | 用途 |
| --- | --- |
| 音乐与音频访问（旧版系统为存储读取） | 扫描和播放本地音乐 |
| 显示在其他应用上层 | 显示悬浮歌词 |
| 使用情况访问 | 识别当前应用，应用对应的歌词颜色；添加配色应用时按需申请 |

固定悬浮歌词可通过点按唤起调整控件；锁定后点击穿透。弹幕歌词始终点击穿透。暂停播放 5 秒后悬浮歌词隐藏，继续播放时恢复；锁屏或 Sona 在前台时隐藏。

## 测试版说明与反馈

1.0 Beta 为测试版本，功能与界面仍会持续完善。不同设备和系统版本上的悬浮窗、系统媒体卡片及音频输出行为可能存在差异。

遇到问题或有功能建议，欢迎提交 [Issue](https://github.com/AIXINJUELUOAI/Sona/issues)。反馈问题时，请尽量提供：

- Sona 版本号、手机型号与 Android／系统版本。
- 问题出现的位置与复现步骤。
- 涉及的歌曲来源，以及当时使用的播放或歌词模式。
- 便于说明问题的截图或录屏。

## 从源码构建

使用 Android Studio 打开项目根目录，准备 JDK 17 或更高版本与 Android SDK 37，然后构建调试版本：

```bash
./gradlew :app:assembleDebug
```

Windows 使用：

```powershell
.\gradlew.bat :app:assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/`。本机 SDK 路径和签名材料不包含在仓库中。
