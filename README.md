# sona

Android 本地与网易云音乐播放器，使用 Kotlin、Jetpack Compose、官方 Material 3 Expressive（M3E）组件和 Media3。

## 第一版

- 首页固定三个区域：每日推荐卡、喜欢入口＋发现歌单轮播、最近播放／私人 FM 分组列表；顶部下拉刷新，刷新失败保留已加载内容。
- 首页、资料库和搜索支持横向切换，也可以使用底部导航。
- 网易云搜索、歌单浏览与分页、二维码登录、网页登录、每日推荐和私人 FM。
- Media3 后台播放、系统媒体控制、播放队列、随机／循环、进度拖动和收藏。
- 底部播放栏与全屏播放器共享容器、封面、标题和播放按钮转场；按钮采用官方形状切换。
- 歌词时间同步、译文、点击歌词定位、自动跟随开关。
- 播放页顶部为媒体输出切换和队列，歌词入口位于歌曲信息旁；长标题与 Live 等版本后缀分层排版。
- 媒体输出使用紧凑的 M3E 单页 sheet，跟随封面取色；标题下显示当前歌曲，标题右侧保留带背景的上一首、播放／暂停、下一首按钮。设备图标带形状底色，选中卡片以圆角及颜色变化反馈，音量图标和百分比整合在设备内的滑杆中。
- 输出选择由后台播放器执行：通过 Media3 指定真实 AudioDeviceInfo，监听播放器 AudioTrack 的实际路由。请求目标与已确认输出分开保存；暂停时显示待播放确认，播放后以实际路由打勾，超时失败保留原输出。设备断开后交回系统选择，关闭 sheet 后继续保持播放器的输出偏好。
- 设备面板首次打开时自动选中系统默认媒体输出；尚未取得实际音频路由时显示“默认设备”，系统路由未知且只有一个可用输出时选中该设备。默认展示不等于切换成功，不触发设备切换，也不直接开放音量滑杆；实际路由确认后显示“当前设备”／“上次输出”，音量仍按实际输出与系统音量目标共同校验。
- 系统媒体音量只在已确认出声设备和系统音量控制目标一致时开放滑杆；目标未确认或系统接口未开放对应控制时使用系统面板入口，避免把蓝牙媒体音量当成手机外放音量。没有用自存的两份数字冒充设备独立音量；Android 13 以下缺少公开的默认媒体路由查询时采用保守校验。
- 播放服务在暂停、切歌、拖动和模式改变时保存队列、当前歌曲、进度、循环模式及随机顺序，播放中每 5 秒补存。服务仍运行时直接接回；冷启动恢复到原位置并保持暂停，点击播放再加载音频。已删除的本地文件会跳过，权限暂时撤回时保留记录；云端保存歌曲编号，播放时重新解析地址。
- 原生风格波浪进度条：官方 Material 波浪轨道＋Slider 拖动语义，播放时流动，暂停／拖动时收平，细竖线滑块。
- 随机／循环／喜欢采用等宽分段按钮，切换状态时变色与变形。
- 首页跟随系统动态配色；播放器、歌词、队列、迷你播放栏跟随封面；支持系统／浅色／深色主题。
- 播放页支持两套样式：默认是居中大封面的传统布局，大胆保留大字歌名和异形封面的错落布局。外观设置提供预览及“默认／大胆／点击切换”；点击切换模式下轻点封面切换并记住上次样式，固定样式下封面不触发切换。两套布局共用播放控制、歌词、队列和输出面板，切换不会重建播放器或改变播放进度。
- 默认播放页的歌名和歌手位于顶栏，超长歌名停顿后单行滚动；封面采用稍大、略向下的圆角方形，专辑仅在此布局中隐藏。当前时间与总时长紧贴波浪进度条下方两端，使用封面主题色。两套样式共用等宽等高的扁圆播放按钮和原有配色；底部左侧为「播放模式｜喜欢」双格胶囊，右侧为独立圆形歌词入口。样式切换时歌名通过约 300ms 的共享边界移动、缩放与交叉淡化衔接，歌手、专辑和时间淡入淡出，底部控件位置固定。
- 本地音乐：通过 MediaStore 读取系统音乐库，支持扫描、离线播放、本地收藏和混合队列；Android 13+ 请求音频权限，旧系统请求存储读取权限。
- 统一搜索：全部／本地／网易云三种来源，本地匹配歌曲名、歌手与专辑；本地结果优先展示，网易云独立分页、去重、失败重试，同名的本地与云端版本分别保留。
- 为你混合推荐：从本地音乐、网易云每日推荐和最近播放中选取最多 30 首。收藏、有效收听和歌手偏好加分，早退跳过与最近听过减分，每第五首优先探索未听歌曲，并尽量避免同歌手连续出现。统计保存在设备上。
- 有效收听按后台实际播放时间累计，满 30 秒或歌曲时长的一半计一次；播放不足阈值且已听至少 2 秒后切换曲目记为跳过。暂停、缓冲和拖动进度不计入收听时间。
- 本地歌词：默认先读取音频内嵌歌词，再读取已选择音乐文件夹中同目录、同文件名的 `.lrc`；已手动指定的 LRC 优先。带时间戳的歌词同步滚动、支持点击跳转，纯文本歌词显示全文；兼容 UTF-8、带 BOM 的 UTF-16 和 GB18030 编码。歌词页仅显示歌词和播放控制，来源标签、文件及文件夹选择等操作留待后续独立 sheet。只读取本地来源，不联网匹配歌词。
- 内嵌歌词通过现有 Media3 提取：支持 MP3 的 USLT/ULT、毫秒时间戳 SYLT/SLT、LYRICS 文本标签，FLAC/Ogg 的歌词注释以及 Media3 能提取的 M4A 歌词标签；具体文件的标签兼容性仍需设备验证。
- WAV 另外扫描 RIFF 区块，包括音频数据之后的 ID3 和 LIST/INFO：使用真实标签补充歌名、歌手、专辑、封面及内嵌歌词。扫描时跳过音频数据，标签信息和封面按文件标识、修改时间及大小缓存，避免反复读取；旧播放历史中的本地歌曲在重新扫描和播放时使用更新后的信息。
- 本地扫描范围是系统标记为音乐的文件，文件移除或权限撤回会提示重新检查。
- 本地页手动刷新会通过系统重新索引已知音频路径，并发现可访问的主存储／SD 卡 Music、Download 文件夹中的音频，再重读列表及 WAV 标签缓存。刷新后同步队列和当前歌曲信息，保留播放进度，重新读取当前本地歌词及系统封面，并显示歌曲数量变化；不申请所有文件访问权限。
- 首页问候语沿用早上（5–10 时）、中午（11–13 时）、下午（14–18 时）、晚上四档，前台每分钟和回到前台时按设备时间重新计算。

客户端直接连接网易云接口，不需要填写第三方服务地址。播放地址由网易云返回，账号权益不足或只有试听时会显示相应提示。

## 打开与构建

使用 Android Studio 打开本目录。环境：JDK 17 或更高、Android SDK 37、最低 Android 10（API 29）。

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

默认单元测试不联网。以下命令额外运行匿名、只读接口联调：

```powershell
$env:SONA_LIVE_SMOKE='1'
.\gradlew.bat :app:testDebugUnitTest --rerun-tasks
```

设备端端到端测试位于 `app/src/androidTest`，会连接网易云公开接口并播放搜索结果的第一首歌曲，不会登录账号或修改远端收藏。可在 Android Studio 中运行 `PlayerJourneyTest`。

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

生成体积优化的可安装预览包：

```powershell
.\gradlew.bat :app:assemblePreview
```

`preview` 使用本机 Android 开发调试密钥签名，供第一版体验；正式分发前应配置独立签名。`local.properties` 是本机 SDK 路径文件，不包含在源码 ZIP 中。

## 代码位置

- `BrowseScreens.kt`：首页、轮播、搜索、资料库、登录与设置。
- `SonaApp.kt`：页面切换、共享播放器转场、底栏拖动。
- `PlayerScreen.kt`：播放、歌词、队列。
- `PlayerControls.kt`：波浪拖动进度条；`MediaOutputSheet.kt`：媒体输出和音量面板；`PlaybackOutput.kt`：设备发现、播放器输出偏好、AudioTrack 实际路由观察及音量目标校验；`OutputSelection.kt`：请求与实际输出的状态规则。
- `Theme.kt`：系统主题、官方 Palette 取色、MaterialColors 色彩角色。
- `MusicViewModel.kt`：页面状态和 MediaController。
- `PlaybackService.kt`：Media3 播放会话、音源解析、播放记忆；`PlaybackSnapshot.kt`：队列与随机顺序的持久化格式。
- `NeteaseApi.kt`、`NeteaseProtocol.kt`：独立实现的网易云客户端与协议。
- `MusicSettings.kt`：偏好、最近播放、Android Keystore 加密的会话保存。

播放页底部为「播放模式／歌词／喜欢」；播放模式统一选择顺序、列表循环、单曲循环或随机，选择时同步更新 Media3 的随机和循环状态。
